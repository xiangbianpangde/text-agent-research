## 观察者 rc1.out 的 "2 STALE" 归因

rc1.out 称 declared 72c3e5f6b1494 != on-disk 0044fb9cd6184、declared 1186a531a33be != on-disk 52f3ee7dda8b1。

实测：live repo 与 v77 归档中这两文件当前 on-disk 均为 72c3e5f6… / 1186a531…，与 declared 完全一致；
git status --porcelain 为空；四个历史提交（adf16ffc/468d9fc/7256f0d/41fe134）中该两文件内容相同。

结论：该 2 条 STALE 源于一次已回滚的瞬时 mutation，非交付态缺陷。交付态不呈现该现象，
不应据此判定交付包 STALE，应在 fresh archive 中重测。
