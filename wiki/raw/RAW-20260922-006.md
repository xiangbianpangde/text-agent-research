## 精确机制（tools/canonical_trace.py，行号为 v77 归档内版本）

  L563  declared[name] = (digest, size)
        → 同名后写覆盖前写，duplicate 被静默折叠，不报错。
  L566  if set(declared) != set(on_disk):
        → 只比较"名字集合"；目录/悬空链接的名字同样出现在 iterdir() 中，故集合仍然相等，
          此处不会报告差异。
  L576  if not frame_path.is_file(): continue
        → 注释声称"上面集合比较已报告"，但集合比较只比名字不比类型，因此非 regular entry
          在此被直接跳过，digest / size / 类型校验全部不发生。

后果：CAS 索引既不是唯一名闭包，也不是 regular immutable frames 的精确闭包；一个被重定向或
malformed 的未引用对象可以留在被消费者判定为 internally valid 的 trace 中。
