## 抓取说明

type_text 下发含特殊字符的字符串时，特殊字符被静默丢弃且无报错（outcome=ok）；set_value 可零丢失绕过

## 证据

```
# 环境
macOS 26.5.1 (25F80) / TextEdit / CUA App Version 1001067 / broker codex-cli 0.154.0-alpha.6.2

# 逐字符对照（输入 → AX 回读）
输入: DET !!$$(()),,:;<<>>??[[\\]]^^__``{{||}}~~ /END3
回读: DET  /END3

输入: CHKA!"#$%&'()*+,-./CHKB:;<=>?@/CHKC
回读: CHKA"#%&'*+-./CHKB=@/CHKC

输入: CHKD[]\^_`{|}~/CHKE abcXYZ/CHKF 中文汉字/CHKG 🚀⚑/END
回读: CHKD/CHKE abcXYZ/CHKF /CHKG /END

输入: PROBE ascii=AZaz09-_+= []{}()<>@#$%^&*/\\ 中文测试 emoji=🚀 flag=⚑ pipe=
回读: PROBE ascii=AZaz09-+= @#%&*/  emoji= flag= pipe=

# 保留集
字母数字  空格  Return  " # % & ' * + - . / = @
# 丢失集（静默、无报错、outcome=ok）
! $ ( ) , : ; < > ? [ ] \ ^ _ ` { | } ~  以及全部非 ASCII（中文/emoji）

# 反证：字符未到达应用（排除渲染问题）
cmd+A -> cmd+C -> pbpaste | xxd
= 4445 5420 202f 454e 4433   ("DET  /END3")

# 实现层锚点（strings SkyComputerUseService）
Unable to get current keyboard layout.
Unable to get keyboard layout data.
Unable to get keyboard layout pointer.
<SAIVirtualKeyPress: %d, %04x, %@>
推断：走虚拟键码 + 当前键盘布局映射，非当前键位的字符无法表达且静默丢弃

# 环境佐证
defaults read com.apple.HIToolbox AppleEnabledInputSources
= ABC 键盘布局 + 中文 com.apple.inputmethod.SCIM(ITABC) + 日文 Kotoeri
当前选中 = com.apple.inputmethod.SCIM.ITABC

# 已验证绕过
computer_use_set_value(element_index=2, value="SETVAL a!b$c(d)e[f]g{h}i|j\k~l`m^n_o:p;q<r>s?t,u 中文 🚀 ^END")
-> cmd+S -> xxd typed.txt 字节完全一致
   含 21 24 28 29 5b 5d 7b 7d 7c 5c 7e 60 5e 5f 与 e4b8ad e69687 (中文) f09f9a80 (🚀)
```
