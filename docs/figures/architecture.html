Layer 5：语义检索兜底（Semantic Fallback） TF-IDF + N-Gram
仅当概念模糊、位置未知或拼写偏差时作为末级建议性（Advisory）检索；
IEEE-754 math.fsum 浮点确定性 + score_q 量化真全序；绝对禁止替代事实推断。
researchctl query --text [T] --semantic
Layer C 事务保障与治理门禁
P1-A Report Finalize Hook Single Atomic Tx
命令：freeze-report
• 校验所有 sources 存在与精确 hash
• 原子写入 REPORT-NNN + sources.yaml
• 生成 ReportFrozen 事件与 receipt
• WAL 崩溃恢复保障，绝无半提交状态
P1-B Definition Revision Gate Evolution & Impact
命令：revise-definition / impact
• 规范定义禁止直接覆盖（不可变版本链 H003@v1 → v2）
• 生成 DefinitionRevised 规范事件
• 自动执行逆向依赖 Impact 分析，向下游受影响实体级联传播 stale
P0-C Reconciler 完整性巡检 Tamper & Drift Guard
命令：reconcile / tx-reconcile
• 自动比对物理文件与索引元数据
• 检测断链、文件内容篡改、孤儿文件
• 检出状态漂移时立即触发 fail_closed
SQLite 派生索引 (.index/) Derived & Rebuildable
• 包含 documents, entities, terms, ngrams
• 派生缓存，绝不作为主真源，可随删随建
• 与文件系统严格保持 Watermark 状态同步
researchctl index [--semantic]
