Tier 2: researchctl 核心引擎四大子系统 (Kernel Subsystem Engines)
Zero-Dependency Pure Python Core
1. 查询与图遍历引擎 queries.py
  • 路由闭集表: query / trace / sources / history / impact 严格分流
  • QueryResult Envelope: 权威度三元组 (canonical/derived/unresolved)
  • 溯源下钻器: 结论 → 整理文件 → 穿透到 Raw 日志
  • 逆向 Impact 规划: 遍历反向 DAG，分析实体变更下游波及面
2. 事务与演化引擎 tx/ (P1-A/B)
  • 全局排他锁: freeze_lock (.researchctl/locks/freeze.lock)
  • 两阶段提交: Staging → Commit → Receipt → Marker 崩溃零污染
  • 版本演化控制器: 不可变版本链 (H003@v1→v2) + DefinitionRevised
  • Receipt 密码学校验: 四件套验证与 a–k 11 项全约束校验
3. 完整性与巡检引擎 indexer / reconciler
  • Merkle 树哈希计算: scan_fingerprint 纳秒级感知文件变动
  • 断链与篡改巡检: 检测 Missing Sources、Hash 不匹配与孤儿文件
  • 状态漂移硬阻断: drift=true 时严格触发 fail_closed
  • 重构与崩溃对齐: WAL 崩溃恢复与索引全自动零数据丢失重建
4. 确定性语义检索引擎 semantic.py (P1-C)
  • NFKC + CJK 分词: Unicode 归一化 + 中文 2-gram + 108 停用词过滤
  • TF-IDF 与字符 N-Gram: 对称双路算法 + IEEE-754 math.fsum
  • 整数排序全序: score_q = round(s * 1e9) 消除跨平台浮点漂移
  • 两阶段构建校验: Schema preflight + Post-write 全量不变量守卫
